## What is MCCompanion?

MCCompanion is a free, all in one Minecraft companion app. The flagship feature is our **Xbox relay network** it lets you join any Minecraft Bedrock server on PlayStation, Xbox and Nintendo Switch without port forwarding or any configuration. On top of that, MCCompanion brings together everything a Minecraft player needs in a single app.

## Features

| Feature | Description |
|---|---|
| 🎮 **Console Relay** | Connect any Bedrock server to PlayStation, Xbox and Nintendo Switch via our always online relay network EU & US regions |
| 🔍 **Player Lookup** | Look up any player by Xbox gamertag, Java username or XUID skin, UUID and crosslinked accounts |
| 🎨 **Skin Editor** | Browse thousands of community skins, customize your own and apply them directly to your account |
| 📖 **Minecraft Wiki** | Full Minecraft wiki built into the app no browser needed |
| 💬 **Friends & Chat** | Add friends, see when they're online and send direct messages |
| 🌐 **Server Browser** | Save and manage your favorite Bedrock and Java servers |

## API

MCCompanion provides a **free public API** at [`api.mccompanion.net`](https://api.mccompanion.net) no authentication required. Endpoints include player lookup, bot status, server metrics and more.
